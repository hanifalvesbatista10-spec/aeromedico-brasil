# Aeromédico Brasil

Site institucional do Aeromédico Brasil — landing page pública e painel
administrativo, construídos com Next.js, TypeScript e Tailwind CSS.

> README completo (instalação, variáveis de ambiente, pendências) será
> adicionado ao final da implementação — ver
> `docs/superpowers/plans/2026-08-25-aeromedico-brasil.md`, Task 11.4.

## Rodando localmente

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).
